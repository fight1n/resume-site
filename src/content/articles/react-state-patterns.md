很多团队一上来就引入全局状态库，结果大半状态其实只活在一个组件里。我的经验是按「作用域」分三层：

## 第一层：组件局部 state

`useState` / `useReducer` 能解决 80% 的问题。表单、开关、局部列表——都该待在组件内部。

## 第二层：跨组件但同页面的状态

用 Context 或状态提升（lifting state up）就够了，不必惊动全局。

## 第三层：真正全局的、跨页面的状态

用户登录态、主题、购物车——这些才值得放进全局 store（Zustand / Redux 等）。

> 原则：状态能小就小，能近就近。作用域越小，越不容易出 bug，也越好测。
